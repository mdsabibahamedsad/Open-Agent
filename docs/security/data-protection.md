# Data Protection

Classification PUBLIC → INTERNAL → CONFIDENTIAL → RESTRICTED → SECRET
(plus explicit requests honored). DLP engine uses high-confidence
secret shapes (cloud keys, tokens, private keys, credentialed DB URLs,
bearers, password assignments) — inspect/classify/redact/allow, no
fuzzy universal blocking. Redaction precedes logs, telemetry,
artifacts, and model context. Retention merges org policy over
unbypassable platform minimums; exports are permission-scoped and
audited.
