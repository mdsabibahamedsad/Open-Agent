# Compliance Controls

Generic control framework (ID, name, description, category, status,
evidence, owner, review) across 9 categories with SOC2/ISO27001/GDPR/
NIST-style mappings stored as metadata. Evidence references audit
events, configs, policies, tests, documents, deployments — evidence
never equals a compliance claim. Posture reports show concrete control
states (no fake scores); drift detection reports desired-vs-active
without auto-applying. No certification is claimed anywhere.
